# Глоссарий

| Термин                            | Определение                                                                                                                                                                                                     |
| --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Алмаз (необработанный)**        | Природный минерал, извлечённый из кимберлитовой породы, не подвергшийся огранке. Является основным товаром компании.                                                                                            |
| **Бриллиант**                     | Огранённый алмаз, используемый в ювелирных изделиях. Стоимость возможных бриллиантов определяет цену необработанного камня.                                                                                     |
| **Оцифровка алмаза**              | Процесс комплексного сканирования и измерения камня (размер, чистота, флуоресценция, внутренние напряжения, трещины, форма и распределение включений) с формированием его цифрового паспорта.                   |
| **Цифровой паспорт камня**        | Набор структурированных данных и мультимедийных материалов (изображения, 3D-модели, результаты измерений), заменяющий покупателю личный осмотр алмаза.                                                          |
| **Онлайн-аукцион**                | Электронные торги, при которых покупатели удалённо оценивают камни по цифровым паспортам и делают ставки через веб-интерфейс.                                                                                   |
| **Промежуточное решение**         | Временная архитектура, обеспечивающая запуск первого онлайн-аукциона в срок до 2 месяцев без доработок существующих ИС, с использованием ручных процессов и внешних сервисов.                                   |
| **Целевое решение**               | Полностью автоматизированная архитектура сквозного процесса онлайн-аукциона, развёрнутая в периметре компании, с защищёнными интеграциями и минимальным ручным участием.                                        |
| **ИС**                            | Информационная система — программный комплекс, автоматизирующий определённый бизнес-процесс компании.                                                                                                           |
| **Кимберлитовая порода**          | Вулканическая горная порода, являющаяся основным источником природных алмазов.                                                                                                                                  |
| **Флуоресценция**                 | Свечение алмаза под воздействием ультрафиолетового излучения; один из ключевых параметров оценки качества камня.                                                                                                |
| **On-premise**                    | Размещение ИТ-сервисов на собственных серверах компании, в её физическом периметре.                                                                                                                             |
| **Частное облако**                | Выделенная облачная инфраструктура, предоставляемая внешним провайдером исключительно для одного клиента.                                                                                                       |
| **Сквозной процесс (end-to-end)** | Бизнес-процесс, охватывающий все этапы от инициации до завершения, проходящий через несколько подразделений и систем без разрывов.                                                                              |
| **Стэйкхолдер**                   | Заинтересованное лицо: лицо или группа, чьи интересы продукт обслуживает или затрагивает — не обязательно пользователь системы.                                                                                 |
| **Фрахт**                         | Плата за использование транспортного средства (судна, самолёта, автомобиля и т. д.) или его части для перевозки груза. Это предмет обязательства между фрахтователем (заказчиком) и фрахтовщиком (перевозчиком) |
| **Букинг**                        | Резервирование места для груза на определённом рейсе (судне), в контейнере или другом транспортном средстве. Это заявка на перевозку и обязательство перевозчика принять груз на определённых условиях          |

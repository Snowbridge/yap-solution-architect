# Fit/Gap-анализ

В двух словах:

* Наибольшей готовностью к целевому состоянию обладают ИС Логистика и
  ИС Бухгалтерия. Изменения в них будут носить лишь количественный характер,
  а не качественный.
* Наибольшие изменения потребуются в ИС Алмазы, т.к. она является SSOT для
  сведений о камнях, а именно эти сведения должны претерпеть радикальное
  качественное изменение. Кроме того, процесс идентификации станет
  асинхронным, приобретет внешних исполнителей и трекинг транспортировки
  алмазов для ряда функций, чего сейчас ИС Алмазы не предусматривает
  ни в каком виде.
* Главный гэп — собственно, онлайн-торги: для этого нет никаких даже
  зачаточных решений. Это, с одной стороны, создает наибольшие трудозатраты,
  а с другой позволяет автоматизировать эту новую функцию без оглядки
  на легаси.

## Список систем

| Система | Тип | Функциональность | Комментарий (что нужно доработать) |
| ------- | ------------------------------------------------------------------- | ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ИС «Алмазы»** | Существующая | Существующая + новая | Расширить учетную карточку алмаза до «Цифрового двойника»; добавить отслеживание внешнего исполнителя и статуса исследования (наряд-заказ / отчет); принимать «Отчет об исследовании». |
| **ИС «Аукцион»** | Существующая | Существующая + новая | Не поддерживает онлайн-формат торгов и не имеет функционала публикации каталогов для клиентов; добавить прием «Протокола онлайн-торгов» для инициации договоров купли-продажи и доставки. |
| **ИС «Логистика»** | Существующая | Существующая | Изменение количественное: новый маршрут перевозки (в лабораторию и обратно); перенаправить поток «Статус исполнения перевозки» в ИС «Алмазы». |
| **ИС «Бухгалтерия»** | Существующая | Существующая | Зарегистрировать нового контрагента (лабораторию); обеспечить актирование и оплату услуг лаборатории на основании данных о выполненных исследованиях. |
| **ИС «Лаборатория»** | Новая (внешняя) | Новая | Оцифровка алмазов и формирование цифрового паспорта; прием «Наряд-заказа на исследование»; передача «Отчета об исследовании»; передача данных об услугах в ИС «Бухгалтерию». |
| **ИС «Онлайн торги»** | Новая | Новая | Инкапсулировать механику торгов (ставки, начало/окончание торгов, определение победителя); прием сведений об аукционах, лотах и участниках из ИС «Аукцион»; формирование «Протокола онлайн-торгов». |
| **Облачные сервисы (→ on-premise)** | Новая (внешние / внутренние) | Новая | Публикация данных о камнях для клиентов; промежуточно — частное облако провайдера, целево — перенос на собственные серверы компании (on-premise). |

## Список интеграций

| Интеграция | Тип | Как будет реализована | Какие передаются данные |
| ------------------------------------------------------------------------------------------------ | -------------------------------------------- | ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| ИС «Алмазы» → ИС «Лаборатория» (наряд-заказ на исследование) | Новая | Автоматически | Новые |
| ИС «Лаборатория» → ИС «Алмазы» (отчет об исследовании) | Новая | Автоматически | Новые (основа цифрового двойника алмаза) |
| ИС «Лаборатория» → ИС «Бухгалтерия» (актирование и оплата услуг) | Новая | Автоматически (в промежуточном решении — вручную, Excel) | Новые |
| ИС «Аукцион» → ИС «Онлайн торги» (сведения об аукционах, лотах, участниках) | Новая | Автоматически | Новые (переносятся существующие данные ИС «Аукцион») |
| ИС «Онлайн торги» → ИС «Аукцион» (протокол онлайн-торгов) | Новая | Автоматически | Новые (по смыслу аналогичны данным, вносимым вручную по итогам офлайн-торгов) |

| ИС «Логистика» → ИС «Алмазы» (статус исполнения перевозки) | Существующая (переиспользуется) | Автоматически | Существующие (новый адресат) |
| ИС «Алмазы» → ИС «Аукцион» (учетные карточки / цифровые двойники) | Существующая | Автоматически | Существующие (расширенные до цифрового двойника) |
| ИС «Аукцион» → ИС «Алмазы» (заявки на перемещение между складами) | Существующая | Автоматически | Существующие |
| ИС «Аукцион» ↔ ИС «Бухгалтерия» (участники, сделки, взаиморасчеты) | Существующая | Автоматически | Существующие (источник сделок — протокол онлайн-торгов) |
| ИС «Аукцион» ↔ ИС «Логистика» (заявки на доставку, статусы продвижения) | Существующая | Автоматически | Существующие |
| ИС «Алмазы» ↔ ИС «Бухгалтерия» (первичные документы склада, документы реализации) | Существующая | Автоматически | Существующие |
| ИС «Логистика» ↔ ИС «Бухгалтерия» (заказы на перевозку, статусы, взаиморасчеты) | Существующая | Автоматически | Существующие |
